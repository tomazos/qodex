# Agent Notes

## Commit and Push Policy

- If a change seems permanent, commit it and push it immediately.
- If in doubt, commit it and push it.
- If a change seems temporary, experimental, or still needs manual testing, commit it locally but do not push it yet.
- For temporary or experimental work, amend the prior local-only commit on the next iteration, or roll it back if the change is undone.
- If multiple changes are logically separate, commit them separately.
